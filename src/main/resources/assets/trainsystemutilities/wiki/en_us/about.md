# About Train System Utilities

Train System Utilities (TSU) is a mod that extends Create's railways. Building on Create's tracks, stations, schedules and signals, it adds operation management, station information displays, electrification, and saving and sharing of train presets.

[[TOC]]

## What it does

| Feature | What it does |
|---|---|
| Station train information | Shows the train stopped at the station and the next train to arrive. |
| Line management | Check stations, trains and timetables on the Management Computer. |
| Monitor integration | Shows route maps, train information and posters on monitors. |
| Line symbols | Create the color and shape of a symbol and assign it to stations. |
| Coupling and decoupling | Couple and split consists with a schedule condition. |
| Electrification | Supplies FE to trains through substations and overhead wires. |
| Train presets | Save consists you built, to place them again or share them online. |

## Mods to use with it {#recommended-mods}

Create handles the basic running of trains and their schedules; TSU extends that operation and the equipment around it. Manta is used as the common base for the screens and is bundled with the current supported versions. For prerequisite mods that must be installed separately, check each download page.

With SAS installed alongside, you can set up announcements that follow the trains' movements. Electrification is combined with equipment that can supply FE. Whether an additional device can be connected depends on the FE support its mod provides, so check that mod.

## Ways to use it

Use it when you want to manage several stations and trains, build stations with matching information displays and equipment, or run lines with overhead wires.

## Development and updates

An update may change the save format or the API. Check the changelog for what changed. For a first setup, trying it out in a test world first makes it easier to bring in.
