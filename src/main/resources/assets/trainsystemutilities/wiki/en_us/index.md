# Train System Utilities Wiki

A guide to the features of Train System Utilities and how to use them. With screen images and 3D models, you can see how operation management, station equipment, electrification and train presets work.

## If you are new

Check the screens and basic operations in "[Getting Started](getting-started.md)", then see the whole range of features in "[About Train System Utilities](about.md)". To manage operations, read on from "[Management Computer](management-computer/overview.md)"; to build train information for a station, from "[Railway Management Block](railway-management.md)".
