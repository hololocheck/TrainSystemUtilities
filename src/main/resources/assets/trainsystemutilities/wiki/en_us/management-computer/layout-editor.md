# Layout Editor

![](bws:trainsystemutilities:wiki/screens/management-computer__layout-edit__en_us.png)

Edit the position and size of the information shown on monitors. Open it from "Layout" on the Management Computer.

[[TOC]]

From the palette, choose the route map, train list, schedule, station count, train count, signal count or clock, and drag it into the preview frame.

| Action | Result |
|---|---|
| Left-drag a panel | Change its position |
| Mouse wheel over a panel | Change its size |
| Select a panel and press Delete | Delete the panel |
| Middle-click a panel | Set the text size (for the route map, the icon sizes too) |
| "Clear All" | Delete every panel |
| "Recommended" | Place the recommended layout |
| "Save" | Save the settings and close |

Adjust the numbers in the detailed settings with the mouse wheel. A value of 0 means automatic, fitted to the size of the monitor and the panel. "Recommended (auto)" resets them all at once.

The saved layout is applied to the monitors linked to the same Management Computer.
