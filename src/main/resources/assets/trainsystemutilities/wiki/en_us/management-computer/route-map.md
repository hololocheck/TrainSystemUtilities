# Route Map

![](bws:trainsystemutilities:wiki/screens/management-computer__route-map__en_us.png)

See the registered track network on a 2D map. It shows station names, how the tracks connect, where the trains are and the state of the signals.

[[TOC]]

Open the Management Computer and choose "My Route Map" from the list at the top left. If no map appears, link the track network with a [Memory Card](../tools/memory-card.md).

| Action | Result |
|---|---|
| Left-drag | Move the view |
| Mouse wheel | Zoom in and out |
| Click a train icon | Show the train's details |
| Click a station icon | Show the station's details in the Stations tab |

If the mouse moves far while you click, it counts as moving the map.
