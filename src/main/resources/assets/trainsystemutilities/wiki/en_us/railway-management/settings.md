# Railway Management Block Monitor Settings

![](bws:trainsystemutilities:wiki/screens/railway-management-settings__en_us.png)

From "Settings" on the [Railway Management Block](../railway-management.md), change the track number, the text size and the clock display.

[[TOC]]

| Item | How to set it |
|---|---|
| Track number | Choose 0 to 99 with the mouse wheel. 0 hides it |
| Track number text size | Adjust with the mouse wheel. 0 is automatic |
| Track number position | Click to switch between left and right |
| Clock | Click to switch between shown and hidden |
| Clock text size | Adjust with the mouse wheel. 0 is automatic |

For double-sided displays, choose the face to edit with "Flip Side". Each face can have its own settings.

## Batch Apply {#batch-apply}

While "Batch Apply" is on, changes to the track number, text sizes, track number position and clock settings are applied to every monitor group registered on this block's [Monitor Link Card](../tools/monitor-link-card.md). The front-face settings go to each group's front face, and the back-face settings to each group's back face. Other Railway Management Blocks are not affected. It is on by default. Turn it off to change monitors individually.
