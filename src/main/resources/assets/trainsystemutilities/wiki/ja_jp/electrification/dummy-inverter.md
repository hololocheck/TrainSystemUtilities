# ダミーインバーター

```embed:item id=trainsystemutilities:fe_inverter_dummy size=48 label=true
```

[FEインバーター](fe-inverter.md)と同じ外観・3ブロック構成の、装飾用設備です。集電、蓄電、FE消費は行いません。

[[TOC]]

パンタグラフの展開・収納や、架線に接触する見た目を演出できます。管理用コンピューターの電化詳細には「(装飾モード)」と表示されます。素手で右クリックしても、専用画面や電力情報は表示しません。

列車に本物のFEインバーターと一緒に搭載することもできます。その場合、電力の管理は本物のインバーターが行います。ダミーだけではFEは蓄えられません。

線路脇の機器箱などの装飾にも使えます。FEインバーター1個をクラフトするとダミーインバーターになり、ダミーインバーター1個をクラフトするとFEインバーターに戻ります。入手用IDは`trainsystemutilities:fe_inverter_dummy`です。
