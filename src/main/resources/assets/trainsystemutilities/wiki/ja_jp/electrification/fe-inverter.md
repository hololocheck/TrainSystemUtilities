# FEインバーター

```embed:item id=trainsystemutilities:fe_inverter size=48 label=true
```

集電したFEを蓄え、列車内で共有する設備です。クリックした位置を中央として、前後に3ブロック分を配置します。設置方向に十分な空間を確保してください。いずれか1ブロックを壊すと、3ブロックまとめて撤去します。

[[TOC]]

| 項目 | 値 |
|---|---|
| 容量 | 50,000 FE |
| 入力上限 | 1回の受け入れにつき5,000 FE |
| 出力 | なし（ほかのブロックへFEを送りません） |

同じ列車のインバーターは、別車両に搭載していても電力を共有します。列車に組み込むと、インバーターを搭載した車両ごとに50,000 FEまで蓄えます。複数の車両に搭載すると、列車全体の容量が増えます。同じ車両に複数台を置いても、その車両の容量は増えません。

設置状態で素手の右クリックをすると、「駆動可」「駆動不可」の状態と、残量・容量をチャットに表示します。列車全体の状態は、管理用コンピューターの電化詳細や[電力チェッカー](power-checker.md)で確認できます。
