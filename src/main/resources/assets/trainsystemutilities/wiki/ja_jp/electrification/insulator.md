# 架線碍子

```embed:item id=trainsystemutilities:insulator size=48 label=true
```

架線の取り付けと、変電所からの給電に使う支持点です。設置したい面を右クリックすると、床では上向き、天井では下向き、壁では横向きに配置します。架線は碍子の先端につながります。

[[TOC]]

[架線接続ツール](wire-connector.md)を設置モードにし、始点と終点の碍子を順に右クリックして接続します。ひとつの碍子に複数の架線をつなぐこともできます。

給電には、[変電所](substation.md)に隣接する碍子から架線網をつなげてください。変電所の電力がなくなると、接続先も通電しなくなります。碍子を壊すと、その碍子につながる架線は撤去されます。

[電力チェッカー](power-checker.md)で右クリックすると、接続本数や通電状態を確認できます。
