# 架線柱

```embed:item id=trainsystemutilities:overhead_pole size=48 label=true
```

単線区間の架線を支える柱です。地面などの上面に右クリックして設置します。向きは45度刻みの8方向に対応します。

[[TOC]]

立っている柱を上から右クリックすると、同じ向きで上に継ぎ足せます。必要な高さにしてから、柱の上に[碍子](insulator.md)を設置してください。架線は柱ではなく、碍子に張ります。

複線区間では[架線トラス](overhead-truss.md)を組み合わせます。線路に合わせた配置を助けたい場合は、[架線柱配置補助ツール](../tools/overhead-pole-auto-tool.md)をご覧ください。
