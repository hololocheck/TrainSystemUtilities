# 架線トラス

```embed:item id=trainsystemutilities:overhead_truss size=48 label=true
```

複数の線路をまたいで架線を支える梁です。45度刻みの8方向に対応し、斜めの区間にも配置できます。

[[TOC]]

設置済みのトラスを右クリックすると、梁の先へ継ぎ足します。斜めの[架線柱](overhead-pole.md)の側面からも、その向きに合わせて配置できます。

各線路の上に[碍子](insulator.md)を取り付け、碍子同士を[架線接続ツール](wire-connector.md)でつないでください。トラス自体に架線は接続できません。[配置補助ツール](../tools/overhead-pole-auto-tool.md)の設定でも、トラスを使う構成を選べます。
