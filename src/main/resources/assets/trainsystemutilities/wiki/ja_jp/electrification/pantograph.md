# パンタグラフ

```embed:item id=trainsystemutilities:pantograph size=48 label=true
```

列車の屋根に取り付ける集電装置です。列車を組み立てる前に、屋根の上面へ設置してください。通電した架線から受け取った電力を、同じ列車の[FEインバーター](fe-inverter.md)へ送ります。

[[TOC]]

設置状態では、素手の右クリックで展開・収納を切り替えます。組み立てた列車は、管理用コンピューターの[列車詳細](../management-computer/trains.md)から操作できます。個別の切り替えに加え、全パンタグラフの展開・収納にも対応します。管理用コンピューターから切り替えられるのは、インバーター（ダミーインバーターを含む）を同じ車両に搭載したパンタグラフで、自分が列車から64ブロック以内にいる必要があります。

展開・収納は手動で切り替えるもので、架線に合わせて自動で動くことはありません。どの方法で切り替えても、最後に行った操作が反映されます。集電するのは、展開していて、通電した架線に接触している間だけです。

パンタグラフとインバーターは、同じ車両に置く必要はありません。同じ列車内で電力を共有できます。架線を離れた区間では、蓄えた電力を利用します。列車全体のFEが0になると、列車は停止します。読み込まれていないチャンクにいる列車は、集電もFEの消費も行いません。
