# 電力チェッカー

```embed:item id=trainsystemutilities:power_checker size=48 label=true
```

電化設備の状態を調べるツールです。手に持って対象を右クリックすると、結果をチャットに表示します。専用の画面は開きません。

[[TOC]]

| 対象 | 確認できること |
|---|---|
| 架線碍子 | 接続している架線数、通電中の本数 |
| キュービクル | ワールド全体の架線数、通電マーク数（FEの量は表示しません） |
| FEインバーター／パンタグラフ | そのブロックの情報（パンタグラフは展開状態）と、64ブロック以内で最も近い電化列車の、列車全体のFE残量、パンタグラフ数、インバーター数、接触中のパンタグラフ数 |

電力が届かない場合は、電源、キュービクル、碍子・架線、パンタグラフ、インバーターの順に確認します。架線が通電しているか、パンタグラフが架線に接触しているか、蓄電量が減り続けていないかを見ると、問題の箇所を探しやすくなります。

対応外のブロックを選ぶと、対象外であることを表示します。
