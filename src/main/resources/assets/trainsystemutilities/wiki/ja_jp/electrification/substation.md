# 変電所キュービクル

```embed:item id=trainsystemutilities:substation size=48 label=true
```

外部からFEを受け取り、架線へ供給する設備です。幅4×高さ3×奥行2ブロックの空間を確保し、設置すると24ブロック分の構造が自動で配置されます。

[[TOC]]

構造内のどれか1ブロックを破壊すると、設備全体を撤去します。

FE電源を接続し、キュービクルの隣に[碍子](insulator.md)を設置します。その碍子から架線を伸ばすと、接続した架線網へ電力を送れます。

| 項目 | 値 |
|---|---|
| 蓄電容量 | 1,000,000 FE |
| 受け入れ上限 | 1回の受け入れにつき10,000 FE |
| 維持コスト | 給電する架線網の架線1本につき1 FE／tick |

設置時にクリックした位置の本体ブロックを素手で右クリックすると、状態、残量・容量、接続数をチャットに表示します。「接続待ち」はFEは残っているが架線を通電できていない状態（碍子・架線がつながっていない、またはFEが維持コストに足りない）、「FE 不足」はFEが0の状態です。「接続待ち」の場合は碍子と架線を、「FE 不足」の場合は電源側を確認してください。詳細な確認には[電力チェッカー](power-checker.md)を使えます。

設備の電力情報はサーバー側で管理し、チャンクが読み込まれていなくても架線への給電を続けます。ただし、外部電源の稼働は、接続する機器の条件も確認してください。
