# Train System Utilities Wiki

Train System Utilitiesの機能と操作方法をまとめたガイドです。画面画像や3Dモデルを見ながら、運行管理、駅設備、電化、列車プリセットの使い方を確認できます。

## 初めて使う方へ

「[はじめに](getting-started.md)」で画面と基本操作を確認し、「[Train System Utilitiesについて](about.md)」で機能の全体像をご覧ください。運行を管理する場合は「[管理用コンピューター](management-computer/overview.md)」、駅の列車案内をつくる場合は「[鉄道管理ブロック](railway-management.md)」から読み進めてください。

## 目的から探す

- 運行を管理する：[管理用コンピューター](management-computer/overview.md)、[路線マップ](management-computer/route-map.md)、[列車](management-computer/trains.md)、[電子式時刻表](management-computer/schedule.md)、[駅](management-computer/stations.md)、[券売機](management-computer/tickets.md)、[路線記号](management-computer/line-symbols.md)
- 表示を整える：[モニター表示](management-computer/monitor.md)、[レイアウトエディタ](management-computer/layout-editor.md)、[色設定](management-computer/color-settings.md)、[路線記号エディタ](management-computer/symbol-editor.md)
- 駅に案内を出す：[鉄道管理ブロック](railway-management.md)、[モニター設定](railway-management/settings.md)、[色設定](railway-management/color.md){{if-mod spatialaudiosystem}}、[アナウンス設定（SAS導入時）](railway-management/announcement.md){{/if}}
- 画像を表示する：[ポスター管理ブロック](poster-management.md)、[アニメーション設定](poster-management/animation.md)
- 編成を運用する：[連結・切り離し](trains/coupling.md)
- 駅と設備を登録する：[駅範囲指定ツール](tools/station-range-tool.md)、[メモリーカード](tools/memory-card.md)、[モニター連携カード](tools/monitor-link-card.md)、[列車検知カード](tools/train-detection-card.md)
- 経路を調べる：[乗り換え案内端末](tools/transit-terminal.md)
- 編成を保存・配置する：[列車プリセット保存](train-preset-tool/save.md)、[素材補充](train-preset-tool/refill.md)、[プリセット閲覧・配置](train-preset-tool/browse.md)
- 編成を共有する：[Preset Place](preset-place/overview.md)、[アップロード](preset-place/upload.md)、[プリセット詳細](preset-place/detail.md)、[プロフィール](preset-place/profile.md)、[クリエイターセンター](preset-place/creator-center.md)
- 路線を電化する：[電化システムの概要](electrification/index.md)、[架線接続ツール](electrification/wire-connector.md)、[カスタム架線](electrification/custom-wire.md)、[パンタグラフ](electrification/pantograph.md)、[FEインバーター](electrification/fe-inverter.md)、[ダミーインバーター](electrification/dummy-inverter.md)、[キュービクル](electrification/substation.md)、[碍子](electrification/insulator.md)、[電力チェッカー](electrification/power-checker.md)、[架線柱](electrification/overhead-pole.md)、[架線トラス](electrification/overhead-truss.md)、[架線柱配置補助ツール](tools/overhead-pole-auto-tool.md)
- 駅をつくる：[ホームフェンス](structure/platform-fence.md)、[ホームドア](structure/platform-screen-door.md)、[券売機](structure/ticket-vending-machine.md)、[駅名サイン](structure/station-name-sign.md)
- 撮影する：[グリーンバック](structure/green-back.md)

操作に迷ったときは、ゲーム内画面の「[ヒント](getting-started.md#hints-and-f1)」を有効にし、調べたい項目にカーソルを合わせてF1を押してください。
