# 管理用コンピューターの色設定

```embed:color-settings
```

モニターの文字や路線図の色を変更します。管理用コンピューターの「色」から開いてください。

[[TOC]]

上部の「対象」で変更する要素を選び、下の色をクリックします。タイトル、枠線、列車名、速度・状態、目的地、時計、統計値、信号、路線、駅、列車アイコンなどを調整できます。

12色のプリセットから選べます。「リセット」で選択した要素を、「全リセット」ですべての要素を既定色に戻します。設定は、同じ管理用コンピューターにリンクしたモニターへ反映されます。
