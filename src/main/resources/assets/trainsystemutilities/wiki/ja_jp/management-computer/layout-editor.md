# レイアウトエディタ

![](bws:trainsystemutilities:wiki/screens/management-computer__layout-edit__ja_jp.png)

モニターに表示する情報の位置と大きさを編集します。管理用コンピューターの「レイアウト」から開きます。

[[TOC]]

パレットから、路線マップ、列車一覧、時刻表、駅数、列車数、信号数、時計を選び、プレビュー枠へドラッグしてください。

| 操作 | 動作 |
|---|---|
| パネルを左ドラッグ | 位置を変更 |
| パネル上でホイール | 大きさを変更 |
| パネルを選択してDelete | パネルを削除 |
| パネルを中クリック | 文字の大きさを設定（路線マップはアイコンの大きさも） |
| 「全消去」 | すべてのパネルを削除 |
| 「おすすめ」 | 推奨レイアウトを配置 |
| 「保存」 | 設定を保存して閉じる |

詳細設定の数値はホイールで調整します。値を0にすると、モニターとパネルの大きさに合わせた自動設定になります。「おすすめ（自動）」でまとめて戻せます。

保存したレイアウトは、同じ管理用コンピューターにリンクしたモニターへ反映されます。
