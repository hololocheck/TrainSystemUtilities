# 路線記号タブ

![](bws:trainsystemutilities:wiki/screens/management-computer__symbol__ja_jp.png)

駅の案内表示で使う路線記号を作成・編集します。管理用コンピューターから「路線記号」を選んでください。

[[TOC]]

「新規作成」で[エディタ](symbol-editor.md)を開きます。既存の記号は左クリックで編集、右クリックで削除確認を表示します。記号には英字2文字と番号、縁の色、角の丸みを設定できます。

作成した記号は、[駅タブ](stations.md)から駅に割り当てます。使用中の記号を削除すると、駅への割り当ても解除されます。

1.0.10以降、記号と割り当ては[メモリーカード](../tools/memory-card.md)に保存します。カードを抜くと、駅モニターの記号は一時的に非表示になります。同じカードを挿し直すと表示が戻ります。
