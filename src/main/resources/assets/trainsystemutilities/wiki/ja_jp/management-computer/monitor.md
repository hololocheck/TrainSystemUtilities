# モニター表示

![](bws:trainsystemutilities:wiki/monitor/monitor-display__ja_jp.png)

*鉄道管理ブロックの駅モニターの表示例（停車中の列車・次に停車する列車・路線記号・番線・時刻）*

管理用コンピューターの情報を、リンクしたモニターに表示できます。路線図、列車一覧、時計などを、レイアウトエディタで自由に配置できます。

[[TOC]]

## 表示までの手順

1. 管理用コンピューターとモニターを設置します。
2. [モニター連携カード](../tools/monitor-link-card.md)で、表示先のモニターを登録します。
3. 登録済みのカードを、管理用コンピューターのモニタースロットに入れます。
4. 「モニター」のスイッチは初期状態で有効です。無効にしている場合は、クリックして有効にします。
5. 「[レイアウト](layout-editor.md)」でパネルを配置して保存します。初期状態のレイアウトは空で、パネルがないと何も表示されません。

「[レイアウト](layout-editor.md)」でパネルの位置と大きさを、「[色](color-settings.md)」で各要素の配色を設定します。カードに複数のモニターを登録している場合、管理用コンピューターは最初に登録したモニターに表示します。
