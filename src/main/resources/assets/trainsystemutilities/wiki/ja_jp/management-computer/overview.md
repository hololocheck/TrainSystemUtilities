# 管理用コンピューターの概要

![](bws:trainsystemutilities:wiki/screens/management-computer__map__ja_jp.png)

路線全体の情報を確認し、列車や駅、モニターを設定する設備です。ブロックを設置して右クリックすると開きます。線路網の登録には[メモリーカード](../tools/memory-card.md)を使います。

[[TOC]]

左上の一覧から、「[自分の路線マップ](route-map.md)」「[列車](trains.md)」「[電子式時刻表](schedule.md)」「[駅](stations.md)」「[路線記号](line-symbols.md)」「[券売機](tickets.md)」の画面を選びます。下部の「[色](color-settings.md)」「[レイアウト](layout-editor.md)」から、モニターの見た目を設定できます。

数値は値の上でホイール、スイッチはクリックで変更します。「ヒント」を有効にしてF1を押すと、カーソルの下の機能の解説を開けます。

## 公開・非公開と設定の保存 {#owner-face}

顔アイコンでは[公開・非公開](../getting-started.md#access-mode)を切り替えます。共同で編集するか、管理する人だけが変更するかに合わせて選んでください。管理用コンピューターの設定は、挿入したメモリーカードに保存できます。保存方法は「[メモリーカード](../tools/memory-card.md)」をご覧ください。
