# 路線マップ

![](bws:trainsystemutilities:wiki/screens/management-computer__route-map__ja_jp.png)

登録した線路網を2Dマップで確認できます。駅名、線路のつながり、列車の位置、信号の状態を表示します。

[[TOC]]

管理用コンピューターを開き、左上の一覧から「自分の路線マップ」を選びます。マップが表示されない場合は、[メモリーカード](../tools/memory-card.md)で線路網をリンクしてください。

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 表示範囲を移動 |
| ホイール | 拡大・縮小 |
| 列車アイコンをクリック | 列車の詳細を表示 |
| 駅アイコンをクリック | 駅タブで駅の詳細を表示 |

クリック時にマウスを大きく動かすと、マップの移動として扱われます。
