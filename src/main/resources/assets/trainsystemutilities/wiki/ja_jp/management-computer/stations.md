# 駅タブ

![](bws:trainsystemutilities:wiki/screens/management-computer__stations__ja_jp.png)

駅名、位置、鉄道管理ブロックとのリンク、路線記号などを確認する画面です。管理用コンピューターから「駅」を選びます。

[[TOC]]

駅の行をクリックすると詳細が開きます。鉄道管理ブロックがリンクしている駅では、列車のドアが開く方向を北・南・東・西・両側・閉から選べます。「戻る」で一覧に戻ります。

![](bws:trainsystemutilities:wiki/screens/management-computer-station-assign__ja_jp.png)

路線記号を割り当てる場合は、先に[路線記号タブ](line-symbols.md)で記号を作成してください。駅の行の割り当てボタンを押し、一覧から記号を選びます。「なし」を選ぶと解除します。設定した記号は駅のモニターや駅名サインなどの表示に反映されます。

駅グループのメンバー、名前、削除などの管理は、[駅範囲指定ツール](../tools/station-range-tool.md)の案内もご覧ください。
