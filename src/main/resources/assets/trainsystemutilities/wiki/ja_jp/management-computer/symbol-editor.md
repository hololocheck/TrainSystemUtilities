# 路線記号エディタ・カラーピッカー

![](bws:trainsystemutilities:wiki/screens/management-computer__symbol-create__ja_jp.png)

路線記号の文字、番号、角の丸み、縁の色を編集します。[路線記号タブ](line-symbols.md)の「新規作成」、または既存記号の左クリックで開きます。

[[TOC]]

## 記号の編集

「文字1」「文字2」はA〜Z、「番号」は00〜99で、欄にカーソルを合わせてホイールで変更します。「アール」では角の丸みを5〜25pxで設定し、20以上で円になります。「縁色」は12色のプリセットからホイールまたはクリックで選びます。上部のプレビューで確認してください。記号は白地に黒の文字で、縁と区切り線が縁色になります。

新規作成はJA・01・アール12pxから始まります。「保存」で一覧に追加し、[駅タブ](stations.md)から割り当てます。

## 色を選ぶ {#color-picker}

![](bws:trainsystemutilities:wiki/screens/management-computer__color-picker__ja_jp.png)

「カラーピッカー」ボタンで開きます。色相のバーと、彩度・明度の面で色を選びます。Hex・RGB・HSLの欄をクリックすると値を入力でき、Enterで反映します。RGBの値は0〜255です。

プレビューで色を確認し、「+ 追加」を押すと縁色に設定され、カスタム色の一覧にも加わります。カスタム色はクリックで使い、右クリックで一覧から外せます。一覧は管理用コンピューターの画面を閉じると消えます。追加せずに閉じた場合は、元の色を保持します。
