# 券売機タブ

![](bws:trainsystemutilities:wiki/screens/management-computer__tickets__ja_jp.png)

[券売機](../structure/ticket-vending-machine.md)で選べる行き先を設定する画面です。管理用コンピューターから「券売機」を選びます。

[[TOC]]

このコンピューターの線路網にある駅グループが一覧に表示されます。各駅のスイッチで、行き先として表示するかを切り替えてください。設定はワールド全体で共有され、すべての券売機に反映されます。

駅が表示されない場合は、先に[駅範囲指定ツール](../tools/station-range-tool.md)で駅グループを登録します。行き先をまだ選択していない初期状態では、同じ線路網にある自駅以外の全駅を表示します。選択を行うと、選んだ駅だけに絞り込まれます。
