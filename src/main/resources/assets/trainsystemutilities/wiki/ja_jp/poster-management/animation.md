# ポスターのアニメーション設定

![](bws:trainsystemutilities:wiki/screens/poster-management-anim__ja_jp.png)

ポスターの切り替え方を設定します。[ポスター管理ブロック](../poster-management.md)の「アニメーション」から開きます。もう一度同じボタンを押すか、Escで閉じられます。

[[TOC]]

一覧から効果を選び、「間隔」と「速度」の値をホイールで変更します。間隔は1枚を表示する時間、速度は切り替え動作にかかる時間です。

| 効果 | 動き |
|---|---|
| なし | 効果を付けずに切り替え |
| スライド左／スライド右 | 左右からスライド |
| スライド上／スライド下 | 上下からスライド |
| フェード | 徐々に切り替え |
| フリップ横 | 横に縮めて裏返すように切り替え |
| ズームイン | 拡大しながら現れる |
| ズーム+フェード | 縮小しながら現れる |
| スライド左+フェード／スライド上+フェード | 短いスライドとフェードで切り替え |

画面内のプレビューで動きを確認できます。プレビューには、登録した画像ではなく2色の見本を使います。
