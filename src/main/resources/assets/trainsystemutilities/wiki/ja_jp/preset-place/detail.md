# プリセットの詳細

![](bws:trainsystemutilities:wiki/screens/preset-place-detail__ja_jp.png)

公開作品の3Dモデル、画像、説明、投稿者を確認する画面です。プリセットプレイスの一覧から作品をクリックすると開きます。

[[TOC]]

「3D」で拡大表示を開き、左ドラッグで回転、Shift＋左ドラッグで移動、ホイールで拡大縮小できます。拡大率は0.2〜8倍です。Escまたは背景のクリックで閉じます。

「DL」で手元に保存します。保存後は「自分のプリセット」から配置できます。いいねは再クリックで解除できます。投稿者名を選ぶと[プロフィール](profile.md)を開き、フォローの切り替えもできます。

![](bws:trainsystemutilities:wiki/screens/preset-place-detail-report__ja_jp.png)

不適切な内容を見つけた場合は「通報」を開き、500文字以内で理由を入力して送信してください。管理者が内容を確認します。
