# Preset Placeの概要

```embed:item id=trainsystemutilities:train_preset_tool size=48 label=true
```

自作の列車プリセットを公開し、ほかのプレイヤーの作品を探してダウンロードできる共有機能です。ログインには、ゲームにログインしているMinecraftアカウントを自動で使います。

[[TOC]]

列車プリセットツールをGUIモードにして右クリックし、左上のドロップダウンを「プリセットプレイス」に切り替えます。作品を選ぶと、3Dプレビュー、画像、説明を確認できます（[プリセットの詳細](detail.md)）。

気に入った作品には、いいねを付けたり、投稿者をフォローしたりできます。ダウンロードした編成は、「自分のプリセット」から配置できます。不適切な投稿は、詳細ページから理由を添えて通報できます。

自分の作品を公開するときは、「自分のプリセット」で自作プリセットのアップロードアイコンを選びます（[プリセットのアップロード](upload.md)）。自分の名前やアイコンから[プロフィール](profile.md)を開き、[クリエイターセンター](creator-center.md)で投稿の反応を確認できます。
