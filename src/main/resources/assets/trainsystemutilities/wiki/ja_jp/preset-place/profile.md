# プロフィール

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__ja_jp.png)

ユーザーの公開作品と投稿状況を確認するページです。自分のプロフィールはプリセットプレイス上部の名前・アイコンから、ほかのユーザーは[作品詳細](detail.md)の投稿者名から開きます。

[[TOC]]

自分のページでは、公開作品数、累計ダウンロード数、いいね数、フォロワー数を確認し、[クリエイターセンター](creator-center.md)を開けます。ほかのユーザーのページでは、公開作品の閲覧とフォローができます。

![](bws:trainsystemutilities:wiki/screens/profile-icon-editor__main__ja_jp.png)

プロフィールアイコンの編集は、対応する公式アカウントに表示されます。SVGを読み込み、大きさ、位置、背景色、枠色を設定できます。一般アカウントには編集ボタンを表示しません。

認証が切れている場合は、画面を開いたときに自動でログインし直します。
