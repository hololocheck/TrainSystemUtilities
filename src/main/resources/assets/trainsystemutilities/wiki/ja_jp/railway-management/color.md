# 鉄道管理ブロックの色設定

![](bws:trainsystemutilities:wiki/screens/railway-management-color__ja_jp.png)

[鉄道管理ブロック](../railway-management.md)の「色」から、案内表示の配色を変更します。「対象」を選び、プリセットの色をクリックしてください。

[[TOC]]

変更できるのは、到着時刻、出発時刻、停車情報、路線の運行形態、停車秒数、列車名、次列車名、セクション見出し、カウントダウン、番線番号の10項目です。路線の運行形態は、環状・折り返しなどを指し、普通・快速などの列車種別とは別です。

12色のプリセットを使用できます。「リセット」で選択した項目を、「全リセット」ですべての項目を初期色に戻します。両面モニターでは、「設定」の「表/裏 切替」で選んだ面ごとに配色を設定できます。配色は鉄道管理ブロックごとの設定で、「一括適用」の対象には含まれません。

この画面ではプリセット色を使います。色相のバーやHEX入力での編集は、路線記号エディタなどの[カラーピッカー](../management-computer/symbol-editor.md#color-picker)をご覧ください。
