# 鉄道管理ブロックのモニター設定

![](bws:trainsystemutilities:wiki/screens/railway-management-settings__ja_jp.png)

[鉄道管理ブロック](../railway-management.md)の「設定」から、番線番号や文字の大きさ、時計の表示を変更します。

[[TOC]]

| 項目 | 設定方法 |
|---|---|
| 番線番号 | ホイールで0〜99を選択。0では非表示 |
| 番線の文字サイズ | ホイールで調整。0は自動 |
| 番線の位置 | クリックで左・右を切り替え |
| 時計 | クリックで表示・非表示を切り替え |
| 時計の文字サイズ | ホイールで調整。0は自動 |

両面表示では「表/裏 切替」で編集する面を選びます。面ごとに異なる設定を使えます。

## 一括適用 {#batch-apply}

「一括適用」を有効にしている間は、番線番号・文字サイズ・番線の位置・時計の設定の変更を、このブロックの[モニター連携カード](../tools/monitor-link-card.md)に登録したすべてのモニターグループへ反映します。表面の設定は各グループの表面に、裏面の設定は各グループの裏面に反映されます。ほかの鉄道管理ブロックには反映されません。初期状態では有効です。個別に変更するときは無効にしてください。
