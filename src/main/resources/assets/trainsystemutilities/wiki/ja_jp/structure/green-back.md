# グリーンバック

```embed:item id=trainsystemutilities:green_back size=48 label=true
```

動画やスクリーンショットの背景に使う、緑色（#00FF00）のブロックです。明るさ15で発光します。撮影後、映像編集ソフトなどで緑色を抜くクロマキー合成に使えます。

通常のブロックと同じように設置・撤去します（回収にはツルハシを使います）。専用画面はありません。車両や建築物の背面に敷き詰め、撮影する範囲を覆ってください。[Preset Place](../preset-place/upload.md)の紹介画像づくりにも使えます。

被写体の下にも敷くと切り抜きやすくなる一方、緑色が映り込む場合があります。撮影方法や編集に合わせて配置を調整してください。
