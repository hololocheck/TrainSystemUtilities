# ホームフェンス

```embed:items size=32 cols=3 label=true ids=trainsystemutilities:platform_fence_1m,trainsystemutilities:platform_fence_3m,trainsystemutilities:platform_fence_5m
```

ホームの縁に設置するフェンスです。1m・3m・5mの3種類を使い分け、帯の色を路線に合わせて変更できます。

[[TOC]]

設置したい向きに体を向け、右クリックしてください。フェンスは自分から見て左右に伸びます。3m・5mは必要な幅が空いていないと設置できません。

帯色をまとめて変えるときは、[メモリーカード](../tools/memory-card.md)で隣接するフェンスやホームドアをグループ登録します。カードを持っている間は、登録範囲を枠で確認できます。不要な部分はShift＋右クリックで外せます（つながった部分ごと外れます）。

登録したカードを[鉄道管理ブロック](../railway-management.md)のホームドア設定に入れ、動作が「帯色」の条件を設定します。色は設定画面の色見本から選び、停車・発車のイベントで変わります。フェンス単体の右クリックでは色は変わりません。詳しい連携手順は「[ホームドア](platform-screen-door.md#link)」をご覧ください。
