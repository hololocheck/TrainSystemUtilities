# ホームドア

```embed:item id=trainsystemutilities:platform_screen_door size=48 label=true
```

列車の到着・発車に合わせて開閉するホームドアです。1台は幅6ブロックで、中央4ブロック分が開きます。右クリックによる手動開閉は行いません。

[[TOC]]

## 設置する {#place}

ホームの縁へ、設置する向きに体を向けて右クリックします。設置点を含む幅6ブロック分の空間が必要です。[フェンス](platform-fence.md)と組み合わせてホームを整えられます。

## 駅と連動させる {#link}

1. [メモリーカード](../tools/memory-card.md)でドアを右クリックし、つながったドア・フェンスを登録します。
2. 枠で対象を確認し、不要な部分はShift＋右クリックで外します（つながった部分ごと外れます）。
3. [鉄道管理ブロック](../railway-management.md)の「機能」からホームドア設定を開き、カードを入れます。
4. イベントと動作の組み合わせを登録します。

「停車→開」「発車→閉」を設定すると、列車に合わせて動きます。イベントは「停車」「発車」、動作は「開」「閉」「帯色」から選び、最大16条件を登録できます。設定画面のテスト操作で確認できます。

列車を検知するのは鉄道管理ブロックです。対象駅の設備にカードを入れてください。番線による絞り込みはなく、どの番線の列車でも停車・発車で動作します。
