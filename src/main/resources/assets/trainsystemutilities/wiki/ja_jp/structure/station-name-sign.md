# 駅名サイン

```embed:items size=48 cols=2 label=true ids=trainsystemutilities:station_name_sign,trainsystemutilities:station_name_sign_pole
```

[駅グループ](../tools/station-range-tool.md)内に設置すると、駅名、路線記号、路線色、隣の駅を自動表示するサインです。横4×高さ1ブロックで、表裏に表示します。サインごとの設定画面はありません。

[[TOC]]

設置場所へ右クリックすると、表示面が自分の方を向きます。横4ブロックの空間が必要です。ポール付きは高さ2ブロックで、天井の下面に設置すると看板本体が1ブロック下へ吊り下がります。

駅名は駅グループ、記号と帯色は割り当てた[路線記号](../management-computer/line-symbols.md)から決まります。隣の駅は線路のつながりから取得します。線路や駅グループを変更した直後は、隣駅の更新まで最大30秒ほどかかる場合があります。

表示がない場合は駅グループの範囲を、帯や記号がない場合は[駅タブ](../management-computer/stations.md)の割り当てと[メモリーカード](../tools/memory-card.md)を確認してください。隣の駅がない場合は、線路の接続と隣駅のグループ登録を確認します。
