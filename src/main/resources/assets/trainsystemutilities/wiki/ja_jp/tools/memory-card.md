# メモリーカード

```embed:item id=trainsystemutilities:memory_card size=48 label=true
```

線路網や駅設備をリンクし、設定を保存するカードです。モニター専用の[連携カード](monitor-link-card.md)、[列車の検知カード](train-detection-card.md)とは別のアイテムです。

[[TOC]]

## 登録とリンク

| 対象 | 右クリックの動作 |
|---|---|
| Createの線路 | 線路ネットワークを登録 |
| ホームドア・フェンス | つながった設備をまとめて登録 |

線路網を登録したカードを管理用コンピューターのカードスロットに入れると、線路網をリンクします。ホームドア・フェンスを外すときは、その設備をShift＋右クリックします（つながった設備ごと外れます）。カードの内容はツールチップで確認できます。ホームドア・フェンス以外でShift＋右クリックすると、初期化の確認画面が開きます。

![](bws:trainsystemutilities:wiki/screens/memory-card-reset__main__ja_jp.png)

## コンピューターの設定を保存する

1.0.10以降、管理用コンピューターのカードスロットに挿したカードへ、路線記号、駅への割り当て、モニターのレイアウト・色、電子式時刻表の共有設定、リンク先などを保存します。

- 設定済みのカード：カードの内容をコンピューターへ復元します。
- 空のカード：コンピューターの現在の設定を保存します。
- 挿入中：その後の編集も自動で保存します。

コンピューターを置き直した場合も、同じカードで設定を復元できます。カードを抜くと駅の路線記号は一時的に非表示になり、挿し直すと戻ります。カード自体の紛失や初期化にはご注意ください。
