# モニター連携カード

```embed:item id=trainsystemutilities:monitor_link_card size=48 label=true
```

モニターの表示先を登録する専用カードです。手に持ってモニターを右クリックすると、つながったモニターをひとつのグループとして登録します。同じグループをもう一度クリックすると登録を解除します。

[[TOC]]

複数のグループを登録でき、ツールチップで登録したモニターのブロック数を確認できます。Shift＋右クリックでは、カードの登録内容をすべて解除します。

表示するには、登録済みカードを[鉄道管理ブロック](../railway-management.md)、[ポスター管理ブロック](../poster-management.md)、[管理用コンピューター](../management-computer/monitor.md)のモニタースロットへ入れます。表示元のブロックをカードで右クリックする必要はありません。管理用コンピューターでは、カードに最初に登録したグループを表示先に使います。表示元でモニター表示がオフになっている場合は、オンにしてください（初期値はオンです）。

ひとつのモニターだけでなく、縦横につなげた表示面にも対応しています。表示面全体へ、列車案内、画像、カスタムレイアウトを映せます。
