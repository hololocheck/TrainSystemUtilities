# 架線柱配置補助ツール

```embed:item id=trainsystemutilities:overhead_pole_auto_tool size=48 label=true
```

柱の高さや線路からの離隔を設定し、線路上の指定地点に[柱](../electrification/overhead-pole.md)を配置するツールです。GUIモードで右クリックして設定を開き、柱、[トラス](../electrification/overhead-truss.md)、[碍子](../electrification/insulator.md)の構成を決めます。

![](bws:trainsystemutilities:wiki/screens/overhead-pole-auto-settings__main__ja_jp.png)

設定後は選択モードに切り替え、Ctrl＋ホイールで「配置する」を選びます。線路に表示されるプレビューを見て、右クリックしてください。1回の右クリックにつき、その地点へ1基を配置します。複線化の設定に応じて、並んだ線路をまたいで配置します。必要な素材が不足している場合は配置しません。

| 操作 | 動作 |
|---|---|
| Alt＋ホイール | 「GUI」と「選択」を切り替え。「配置する」では向きを45度ずつ8方向に回転 |
| Ctrl＋ホイール | 選択モード内で「GUIへ戻る」と「配置する」を切り替え |
| Shift＋ホイール | 柱の高さを調整 |
| Shift＋中クリック | 見ているチェストを、素材を取り出すチェストとしてリンク |

設定から配置までの流れは、掲載しているチュートリアル動画でも確認できます。
