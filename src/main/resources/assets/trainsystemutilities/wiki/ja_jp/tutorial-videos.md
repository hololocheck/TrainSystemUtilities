# チュートリアル動画

TSUの操作を動画で確認できます。見たい動画のカードを選んで再生してください。対応するゲーム内Wikiでは、ゲームを離れずに視聴できます。

## 列車の電化

[電化システム](electrification/index.md)の導入の流れを、キュービクルの設置から、パンタグラフで集めた電力で列車が走るまで紹介します。

```embed:youtube url=https://youtu.be/p5o8KkhweF8 title="TSU Guide: Create Train Electrification"
```

## 架線柱の自動設置

[架線柱配置補助ツール](tools/overhead-pole-auto-tool.md)で、設定画面から、右クリックした線路に柱を立てるまでの流れを紹介します。

```embed:youtube url=https://youtu.be/ecg9SXoiEd4 title="TSU Guide: Automatic Catenary Pole Placement"
```

## ゲーム内動画の使い方

Wiki内の動画と、小さな別画面で再生する機能の操作を紹介します。

```embed:youtube url=https://youtu.be/fe9IFzxCVlk title="Manta Guide: Use the In-Game Video System"
```

初回の動画利用時には、再生用ランタイムがダウンロードされます。利用できない環境では、カードに表示される案内をご確認ください。

基本操作を文章で調べたい場合は「[はじめに](getting-started.md)」をご覧ください。
