# 逆变器占位方块

```embed:item id=trainsystemutilities:fe_inverter_dummy size=48 label=true
```

外观和 3 方块结构都与 [FE 逆变器](fe-inverter.md)相同的装饰用设备。不集电、不蓄电，也不消耗 FE。

[[TOC]]

可以演出受电弓的升起、降下，以及接触接触网的样子。在管理用计算机的电气化详情中会显示"（装饰模式）"。空手右键也不会显示专用界面或电力信息。

也可以和真正的 FE 逆变器一起搭载在列车上，此时由真正的逆变器管理电力。只有逆变器占位方块时无法储存 FE。

也可以用作轨道旁设备箱等装饰。合成 1 个 FE 逆变器会得到逆变器占位方块，合成 1 个逆变器占位方块会变回 FE 逆变器。获取用 ID 为 `trainsystemutilities:fe_inverter_dummy`。
