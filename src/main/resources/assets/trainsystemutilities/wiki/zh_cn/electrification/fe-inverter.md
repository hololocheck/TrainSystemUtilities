# FE 逆变器

```embed:item id=trainsystemutilities:fe_inverter size=48 label=true
```

储存集电得到的 FE，并在列车内共享的设备。以点击位置为中心，沿前后方向配置 3 个方块。请在放置方向上留出足够的空间。破坏其中任意 1 个方块，3 个方块会一起被拆除。

[[TOC]]

| 项目 | 数值 |
|---|---|
| 容量 | 50,000 FE |
| 输入上限 | 每次接收 5,000 FE |
| 输出 | 无（不向其他方块输送 FE） |

同一列车的逆变器即使搭载在不同车厢上，也会共享电力。组装进列车后，每节搭载逆变器的车厢最多储存 50,000 FE。在多节车厢上搭载，整列车的容量会增加；在同一节车厢上放置多台，该车厢的容量不会增加。

作为方块放置时空手右键，会在聊天栏显示"可驱动""不可驱动"状态以及余量与容量。整列车的状态，可以通过管理用计算机的电气化详情或[电力检查器](power-checker.md)查看。
