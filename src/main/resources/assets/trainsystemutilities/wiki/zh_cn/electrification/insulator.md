# 接触网绝缘子

```embed:item id=trainsystemutilities:insulator size=48 label=true
```

用于安装接触网、并承接变电所供电的支撑点。右键想要放置的面：在地面上朝上、在天花板上朝下、在墙上朝侧面放置。接触网连接在绝缘子的顶端。

[[TOC]]

将[接触网连接工具](wire-connector.md)切换到铺设模式，依次右键起点和终点的绝缘子即可连接。一个绝缘子可以连接多条接触网。

供电时，请从与[变电所](substation.md)相邻的绝缘子连起接触网网络。变电所的电力耗尽后，连接的接触网也会断电。破坏绝缘子时，连接到该绝缘子的接触网会被拆除。

用[电力检查器](power-checker.md)右键，可以查看连接数和通电状态。
