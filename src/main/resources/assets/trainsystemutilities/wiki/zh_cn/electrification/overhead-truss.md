# 接触网桁架

```embed:item id=trainsystemutilities:overhead_truss size=48 label=true
```

横跨多条线路支撑接触网的横梁。支持以 45 度为单位的 8 个方向，也可以放置在斜向区间。

[[TOC]]

右键已放置的桁架，会在横梁末端接长。也可以从斜向[接触网支柱](overhead-pole.md)的侧面，按其朝向放置。

请在每条线路上方安装[绝缘子](insulator.md)，并用[接触网连接工具](wire-connector.md)把绝缘子相互连接。桁架本身无法连接接触网。在[布置辅助工具](../tools/overhead-pole-auto-tool.md)的设置中，也可以选择使用桁架的布置方式。
