# 受电弓

```embed:item id=trainsystemutilities:pantograph size=48 label=true
```

安装在列车车顶的集电装置。请在组装列车之前，把它放在车顶的上表面。它会把从已通电接触网接收的电力，送到同一列车的 [FE 逆变器](fe-inverter.md)。

[[TOC]]

作为方块放置时，空手右键可在升起和降下之间切换。组装后的列车，可以在管理用计算机的[列车详情](../management-computer/trains.md)中操作。除了逐个切换，也可以一次升起或降下全部受电弓。管理用计算机只能切换同一节车厢上搭载了逆变器（包括逆变器占位方块）的受电弓，并且你需要位于列车 64 方块以内。

升起和降下需要手动切换，受电弓不会配合接触网自动动作。无论用哪种方式切换，都以最后一次操作为准。只有在升起状态并接触已通电的接触网时才会集电。

## 多节编组时的行为 {#複数連結時の挙動}

受电弓和逆变器不必放在同一节车厢上，同一列车内可以共享电力。在离开接触网的区间，列车使用储存的电力。整列车的 FE 降到 0 时，列车会停下。位于未加载区块中的列车既不集电，也不消耗 FE。
