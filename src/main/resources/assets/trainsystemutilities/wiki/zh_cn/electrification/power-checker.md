# 电力检查器

```embed:item id=trainsystemutilities:power_checker size=48 label=true
```

检查电气化设备状态的工具。手持它右键目标，结果会显示在聊天栏。不会打开专用界面。

[[TOC]]

| 目标 | 可查看的内容 |
|---|---|
| 接触网绝缘子 | 连接的接触网数量、通电中的数量 |
| 箱式变电站 | 整个世界的接触网数量和通电标记数量（不显示 FE 量） |
| FE 逆变器 / 受电弓 | 该方块的信息（受电弓为升起状态），以及 64 方块以内最近的电力列车（整列车合计）的 FE 余量、受电弓数、逆变器数、正在接触的受电弓数 |

电力送不到时，请按电源、箱式变电站、绝缘子与接触网、受电弓、逆变器的顺序检查。查看接触网是否通电、受电弓是否接触接触网、储电量是否持续减少，更容易找到问题所在。

选择不支持的方块时，会显示它不是目标。
