# Train System Utilities Wiki

汇总 Train System Utilities 各项功能和操作方法的指南。可以一边查看界面图片和 3D 模型，一边了解运行管理、车站设备、电气化和列车预设的用法。

## 初次使用

请先在「[快速开始](getting-started.md)」中了解界面和基本操作，再在「[关于 Train System Utilities](about.md)」中查看功能全貌。要管理运行，请从「[管理用计算机](management-computer/overview.md)」开始阅读；要制作车站的列车信息，请从「[铁路管理方块](railway-management.md)」开始阅读。
