# 布局编辑器

![](bws:trainsystemutilities:wiki/screens/management-computer__layout-edit__zh_cn.png)

编辑显示器上所显示信息的位置和大小。从管理用计算机的「布局」打开。

[[TOC]]

从面板栏中选择线路图、列车列表、时刻表、车站数、列车数、信号机数、时钟，并拖到预览框中。

| 操作 | 效果 |
|---|---|
| 左键拖动面板 | 更改位置 |
| 在面板上滚动滚轮 | 更改大小 |
| 选中面板后按 Delete | 删除面板 |
| 中键点击面板 | 设置文字大小（线路图还可设置图标大小） |
| 「全部清除」 | 删除所有面板 |
| 「推荐」 | 放置推荐布局 |
| 「保存」 | 保存设置并关闭 |

详细设置的数值用滚轮调整。将值设为 0 时，会根据显示器和面板的大小自动设置。按「推荐（自动）」可以一并恢复。

保存的布局会反映到链接到同一台管理用计算机的显示器上。
