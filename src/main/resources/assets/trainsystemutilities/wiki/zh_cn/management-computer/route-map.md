# 线路图

![](bws:trainsystemutilities:wiki/screens/management-computer__route-map__zh_cn.png)

可以在 2D 地图上查看已登记的线路网。显示站名、轨道的连接、列车的位置和信号的状态。

[[TOC]]

打开管理用计算机，从左上角的列表中选择「我的线路图」。如果地图没有显示，请用[存储卡](../tools/memory-card.md)链接线路网。

| 操作 | 效果 |
|---|---|
| 左键拖动 | 移动显示范围 |
| 滚轮 | 放大・缩小 |
| 点击列车图标 | 显示列车详情 |
| 点击车站图标 | 在车站标签页中显示车站详情 |

点击时大幅移动鼠标，会被视为移动地图。
