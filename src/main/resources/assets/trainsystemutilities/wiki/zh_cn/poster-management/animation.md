# 海报动画设置

![](bws:trainsystemutilities:wiki/screens/poster-management-anim__zh_cn.png)

设置海报的切换方式。从[海报管理方块](../poster-management.md)的「动画」打开。再次按同一按钮或按 Esc 即可关闭。

[[TOC]]

从列表中选择效果，用滚轮更改「间隔」和「速度」的值。间隔是每张图片的显示时间，速度是切换动作所需的时间。

| 效果 | 动作 |
|---|---|
| 无 | 不加效果直接切换 |
| 向左滑动／向右滑动 | 从左右滑入 |
| 向上滑动／向下滑动 | 从上下滑入 |
| 淡入淡出 | 逐渐切换 |
| 横向翻转 | 横向收缩，像翻面一样切换 |
| 放大 | 边放大边出现 |
| 缩放 + 淡出 | 边缩小边出现 |
| 左滑 + 淡出／上滑 + 淡出 | 以短距离滑动和淡化切换 |

可以在界面内的预览中确认动作。预览使用双色样本，而不是登记的图片。
