# Preset Place 概述

```embed:item id=trainsystemutilities:train_preset_tool size=48 label=true
```

公开自制的列车预设，并查找和下载其他玩家作品的共享功能。登录时会自动使用当前登录游戏的 Minecraft 账户。

[[TOC]]

将列车预设工具切换到 GUI 模式后右键，并将左上角的下拉菜单切换为「PresetPlace」。选择作品后，可以查看 3D 预览、图片和说明（[预设详情](detail.md)）。

可以为喜欢的作品点赞，或关注投稿者。下载的编组可以从「我的预设」放置。不当的投稿可以在详情页面附上理由进行举报。

公开自己的作品时，在「我的预设」中选择自制预设的上传图标（[上传预设](upload.md)）。从自己的名字或图标打开[个人资料](profile.md)，可以在[创作者中心](creator-center.md)查看投稿的反响。
