# 个人资料

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__zh_cn.png)

查看用户公开作品和投稿情况的页面。自己的个人资料从 PresetPlace 上方的名字・图标打开，其他用户的从[作品详情](detail.md)的投稿者名称打开。

[[TOC]]

在自己的页面中，可以查看公开作品数、累计下载数、点赞数和关注者数，并打开[创作者中心](creator-center.md)。在其他用户的页面中，可以浏览公开作品并关注。

![](bws:trainsystemutilities:wiki/screens/profile-icon-editor__main__zh_cn.png)

支持的官方账户会显示个人资料图标的编辑功能。可以读取 SVG，并设置大小、位置、背景色和边框颜色。普通账户不显示编辑按钮。

登录已过期时，打开界面时会自动重新登录。
