# 上传预设

![](bws:trainsystemutilities:wiki/screens/preset-place-upload__zh_cn.png)

将保存的自制编组提交到 Preset Place 申请公开。请将[浏览界面](../train-preset-tool/browse.md)切换为「我的预设」，并选择目标的上传图标。添加图片或发布时会自动登录。

[[TOC]]

添加 1〜5 张图片，并输入 1〜4,096 个字符的说明。图片支持 PNG・JPG。说明中可以使用 Markdown 的标题、列表、链接、强调和引用。可以在预览中确认显示效果。

填写完整后即可选择「发布」。请在确认界面中确认内容后提交。也可以用 Ctrl + Enter 进行发布操作。申请内容经过审核后公开。

在可以使用 Preset Place 的环境中，自制的预设上会显示上传图标。从 Preset Place 下载的作品上不会显示。
