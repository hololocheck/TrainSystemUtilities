# 显示器连接卡

```embed:item id=trainsystemutilities:monitor_link_card size=48 label=true
```

专门用于登记显示器显示目标的卡片。手持卡片右键显示器，会将相连的显示器登记为一个组。再次点击同一组会取消登记。

[[TOC]]

可以登记多个组，工具提示中会显示已登记的显示器方块数。Shift + 右键会清除卡片上登记的全部内容。

要显示时，请将登记好的卡片放入[铁路管理方块](../railway-management.md)、[海报管理方块](../poster-management.md)或[管理用计算机](../management-computer/monitor.md)的显示器槽位。不需要用卡片右键显示源方块。管理用计算机会使用卡片上最先登记的组作为显示目标。如果显示源的显示器显示已关闭，请将其打开（初始为打开）。

不仅支持单台显示器，也支持纵横拼接的显示面。可以在整个显示面上显示列车信息、图片和自定义布局。
