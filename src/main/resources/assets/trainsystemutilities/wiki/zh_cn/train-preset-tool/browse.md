# 浏览・放置预设

![](bws:trainsystemutilities:wiki/screens/train-preset-browse-mine__zh_cn.png)

选择已保存的编组、确认所需材料并进行放置的界面。将列车预设工具切换到 GUI 模式后右键。

[[TOC]]

## 选择编组

用左上角的下拉菜单在「我的预设」和「PresetPlace」之间切换。「我的预设」是本地保存的编组，「PresetPlace」是 [Preset Place](../preset-place/overview.md) 上的公开作品。

选择自己预设的图块会显示 3D 预览。左键拖动旋转，右键拖动移动，滚轮缩放。选择 PresetPlace 的图块会打开详情界面。右键自己预设的图块会打开删除确认。从自制预设的上传图标可以[申请公开](../preset-place/upload.md)。

公开作品可以按名称搜索，并按「最新」「热门」「下载」「浏览」排序。下载后从「我的预设」中使用。

## 准备材料

将图块拖到右侧面板，可以查看所需材料。在补充来源按钮上滚动滚轮，选择 Chest 或 ME。手持工具 Shift + 中键点击箱子即可链接。

请从胶水储罐的「补充」补给黏合剂（[材料补充](refill.md)）。「倾倒」会丢弃储罐中的全部内容。

## 放置到世界中

按「使用此设置继续」并在确认界面中确定后，会关闭界面并进入放置模式。在放置模式下，用 Alt + 滚轮在「起点」「旋转」「放置」之间切换。在「起点」下右键轨道确定起点。方向会自动决定，需要时可以在「旋转」下滚动 Ctrl + 滚轮，每次修正 90 度。在「放置」下右键即可放置，并消耗材料和黏合剂（创造模式下只消耗黏合剂）。

可以重试时用中键点击重试。用 Shift + 中键点击中止，并返回 GUI 模式。
