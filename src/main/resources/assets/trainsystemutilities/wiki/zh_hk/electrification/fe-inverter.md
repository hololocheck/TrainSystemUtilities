# FE 逆變器

```embed:item id=trainsystemutilities:fe_inverter size=48 label=true
```

儲存集電得到的 FE，並在列車內共享的設備。以點擊位置為中心，沿前後方向配置 3 個方塊。請在放置方向上留出足夠的空間。破壞其中任意 1 個方塊，3 個方塊會一起被拆除。

[[TOC]]

| 項目 | 數值 |
|---|---|
| 容量 | 50,000 FE |
| 輸入上限 | 每次接收 5,000 FE |
| 輸出 | 無（不向其他方塊輸送 FE） |

同一列車的逆變器即使搭載在不同車廂上，也會共享電力。組裝進列車後，每節搭載逆變器的車廂最多儲存 50,000 FE。在多節車廂上搭載，整列車的容量會增加；在同一節車廂上放置多台，該車廂的容量不會增加。

作為方塊放置時空手右鍵，會在聊天欄顯示「可驅動」「不可驅動」狀態以及餘量與容量。整列車的狀態，可以通過管理用計算機的電氣化詳情或[電力檢查器](power-checker.md)查看。
