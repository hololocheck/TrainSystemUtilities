# 接觸網支柱

```embed:item id=trainsystemutilities:overhead_pole size=48 label=true
```

在單線區間支撐接觸網的支柱。右鍵地面等方塊的上表面即可放置。朝向支持以 45 度為單位的 8 個方向。

[[TOC]]

從上方右鍵已立起的支柱，可以以相同朝向向上接長。達到所需高度後，請在支柱頂部放置[絕緣子](insulator.md)。接觸網架設在絕緣子上，而不是支柱上。

複線區間請組合使用[接觸網桁架](overhead-truss.md)。如需配合線路輔助佈置，請參閱[接觸網支柱佈置輔助工具](../tools/overhead-pole-auto-tool.md)。
