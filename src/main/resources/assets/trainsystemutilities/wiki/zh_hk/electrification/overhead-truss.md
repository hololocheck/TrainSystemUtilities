# 接觸網桁架

```embed:item id=trainsystemutilities:overhead_truss size=48 label=true
```

橫跨多條線路支撐接觸網的橫樑。支持以 45 度為單位的 8 個方向，也可以放置在斜向區間。

[[TOC]]

右鍵已放置的桁架，會在橫樑末端接長。也可以從斜向[接觸網支柱](overhead-pole.md)的側面，按其朝向放置。

請在每條線路上方安裝[絕緣子](insulator.md)，並用[接觸網連接工具](wire-connector.md)把絕緣子互相連接。桁架本身無法連接接觸網。在[佈置輔助工具](../tools/overhead-pole-auto-tool.md)的設置中，也可以選擇使用桁架的佈置方式。
