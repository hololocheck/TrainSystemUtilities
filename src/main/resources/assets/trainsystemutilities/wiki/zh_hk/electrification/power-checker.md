# 電力檢查器

```embed:item id=trainsystemutilities:power_checker size=48 label=true
```

檢查電氣化設備狀態的工具。手持它右鍵目標，結果會顯示在聊天欄。不會打開專用界面。

[[TOC]]

| 目標 | 可查看的內容 |
|---|---|
| 接觸網絕緣子 | 連接的接觸網數量、通電中的數量 |
| 箱式變電站 | 整個世界的接觸網數量和通電標記數量（不顯示 FE 量） |
| FE 逆變器 / 受電弓 | 該方塊的信息（受電弓為升起狀態），以及 64 方塊以內最近的電力列車（整列車合計）的 FE 餘量、受電弓數、逆變器數、正在接觸的受電弓數 |

電力送不到時，請按電源、箱式變電站、絕緣子與接觸網、受電弓、逆變器的順序檢查。查看接觸網是否通電、受電弓是否接觸接觸網、儲電量是否持續減少，更容易找到問題所在。

選擇不支持的方塊時，會顯示它不是目標。
