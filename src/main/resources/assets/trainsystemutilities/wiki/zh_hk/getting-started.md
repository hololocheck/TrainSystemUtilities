# 快速開始

本頁面向初次使用 TSU 的玩家，介紹界面的打開方式和通用操作。需要安裝對應版本的 Create。具體的前置版本請查看下載頁面。

[[TOC]]

## 打開界面

| 操作對象 | 打開方式・作用 |
|---|---|
| [管理用計算機](management-computer/overview.md) | 放置後右鍵。管理線路圖、列車和時刻表。 |
| [鐵路管理方塊](railway-management.md) | 右鍵 Create 的車站方塊登記車站，放置後右鍵。設置車站的列車信息和聯動功能。 |
| [海報管理方塊](poster-management.md) | 放置後右鍵。設置圖片和幻燈片。 |
| [自動售票機](structure/ticket-vending-machine.md) | 放置在車站組內後右鍵。選擇目的地並出票。 |
| [換乘查詢終端](tools/transit-terminal.md) | 手持並右鍵。查詢路線和時刻表。 |
| [車站範圍指定工具](tools/station-range-tool.md) | 用 Alt + 鼠標滾輪選擇模式，進行範圍指定或車站管理。 |
| [列車預設工具](train-preset-tool/save.md) | 在 GUI 模式下右鍵。瀏覽、放置和共享編組。 |
| [接觸網連接工具](electrification/wire-connector.md) | 在鋪設模式下連接絕緣子。在 GUI 模式下右鍵會打開設置界面。 |
| [接觸網支柱佈置輔助工具](tools/overhead-pole-auto-tool.md) | 在 GUI 模式下設置，在選擇模式下沿軌道放置。 |

## 通用操作

按鈕和開關用點擊操作；數值將光標移到數值上，用滾輪更改。列表較長時，在列表上滾動滾輪即可滾動。

## 提示與 F1 {#hints-and-f1}

打開界面右上角的「提示」後，將光標在項目上停留約 1 秒，左下角會顯示其説明。説明顯示期間持續操作（移動光標、點擊、滾輪、按鍵）2 秒後説明會消失，再次停留又會顯示。F1 無需等待，按下即可跳轉到光標所指功能的 Wiki。用 Wiki 按鈕也可以打開整個界面的説明。

## 選擇公開・非公開 {#access-mode}

點擊頭像圖標可以切換公開・非公開。設為非公開後，只有所有者能打開界面（OP 也無法打開）。多人共同設置的設備設為公開，管理員想保持設置的設備設為非公開會比較方便。用卡片讀取・鏈接與在界面上更改設置的處理方式不同。

## 界面大小

操作界面會按照 Minecraft 的 GUI 縮放顯示。在支持調整大小的對話框中，可以拖動右下角的把手調整大小。
