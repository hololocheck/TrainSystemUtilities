# Train System Utilities Wiki

匯總 Train System Utilities 各項功能和操作方法的指南。可以一邊查看界面圖片和 3D 模型，一邊了解運行管理、車站設備、電氣化和列車預設的用法。

## 初次使用

請先在「[快速開始](getting-started.md)」中了解界面和基本操作，再在「[關於 Train System Utilities](about.md)」中查看功能全貌。要管理運行，請從「[管理用計算機](management-computer/overview.md)」開始閲讀；要製作車站的列車信息，請從「[鐵路管理方塊](railway-management.md)」開始閲讀。
