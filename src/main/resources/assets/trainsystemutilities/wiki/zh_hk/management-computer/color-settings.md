# 管理用計算機的顏色設置

```embed:color-settings
```

更改顯示器上文字和線路圖的顏色。從管理用計算機的「顏色」打開。

[[TOC]]

在上方的「目標」中選擇要更改的元素，再點擊下方的顏色。可以調整標題、邊框、列車名、速度・狀態、目的地、時鐘、統計數值、信號、線路、車站、列車圖標等。

可以從 12 種預設顏色中選擇。「重置」會將所選元素、「全部重置」會將所有元素恢復為初始顏色。設置會反映到鏈接到同一台管理用計算機的顯示器上。
