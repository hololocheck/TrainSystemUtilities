# 佈局編輯器

![](bws:trainsystemutilities:wiki/screens/management-computer__layout-edit__zh_hk.png)

編輯顯示器上所顯示信息的位置和大小。從管理用計算機的「佈局」打開。

[[TOC]]

從面板欄中選擇線路圖、列車列表、時刻表、車站數、列車數、信號機數、時鐘，並拖到預覽框中。

| 操作 | 效果 |
|---|---|
| 左鍵拖動面板 | 更改位置 |
| 在面板上滾動滾輪 | 更改大小 |
| 選中面板後按 Delete | 刪除面板 |
| 中鍵點擊面板 | 設置文字大小（線路圖還可設置圖標大小） |
| 「全部清除」 | 刪除所有面板 |
| 「推薦」 | 放置推薦佈局 |
| 「保存」 | 保存設置並關閉 |

詳細設置的數值用滾輪調整。將值設為 0 時，會根據顯示器和面板的大小自動設置。按「推薦（自動）」可以一併恢復。

保存的佈局會反映到鏈接到同一台管理用計算機的顯示器上。
