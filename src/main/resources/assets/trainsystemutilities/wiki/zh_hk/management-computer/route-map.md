# 線路圖

![](bws:trainsystemutilities:wiki/screens/management-computer__route-map__zh_hk.png)

可以在 2D 地圖上查看已登記的線路網。顯示站名、軌道的連接、列車的位置和信號的狀態。

[[TOC]]

打開管理用計算機，從左上角的列表中選擇「我的線路圖」。如果地圖沒有顯示，請用[存儲卡](../tools/memory-card.md)鏈接線路網。

| 操作 | 效果 |
|---|---|
| 左鍵拖動 | 移動顯示範圍 |
| 滾輪 | 放大・縮小 |
| 點擊列車圖標 | 顯示列車詳情 |
| 點擊車站圖標 | 在車站標籤頁中顯示車站詳情 |

點擊時大幅移動鼠標，會被視為移動地圖。
