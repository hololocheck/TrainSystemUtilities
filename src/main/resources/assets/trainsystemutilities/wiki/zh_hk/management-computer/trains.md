# 列車標籤頁

![](bws:trainsystemutilities:wiki/screens/management-computer__trains__zh_hk.png)

以列表查看已登記線路網中的列車。請從管理用計算機左上角選擇「列車」。

[[TOC]]

列表中顯示列車名、車廂數、目的地，以及停靠中的車站或行駛中的速度。點擊某一行，可以查看編組的 3D 預覽和時刻表。

![](bws:trainsystemutilities:wiki/screens/management-computer-train-detail__zh_hk.png)

3D 預覽中，左鍵拖動旋轉，Shift + 拖動移動，滾輪縮放。從「查看電氣化狀態」可以查看每節車廂的儲電量、受電弓、FE 逆變器，以及受電弓是否接觸接觸網。

![](bws:trainsystemutilities:wiki/screens/management-computer-electrification-detail__zh_hk.png)

在電氣化詳情中，位於列車 64 個方塊以內時，點擊[受電弓](../electrification/pantograph.md)圖標可以切換升起・降下。用關閉按鈕返回列車詳情。
