# 創作者中心

顯示你自己發佈內容的詳細數據分析的儀表盤。

[[TOC]]

## 打開 {#open}

創作者中心從**你自己的**[**個人資料**](profile.md)**頁**打開。

1. 在 **GUI 模式**下**右鍵**[列車預設工具](../train-preset-tool/browse.md)，打開瀏覽界面（用 **Alt + 滾輪**切換模式）。
2. 將模式設為 **`Place`（公開）**，並**左鍵**頂部的你的名字 / 圖標區域，打開你自己的主頁。
3. 在你的主頁中**左鍵"創作者中心"按鈕**。

> [!NOTE]
> 創作者中心僅限你自己的賬號使用，無法從其他用户的主頁打開（那裏不會顯示該按鈕）。

## 顯示內容

| 項目 | 概要 |
|---|---|
| 發佈數 | 已發佈預設的總數 |
| 累計下載 | 所有預設的下載總量 |
| 累計點贊 | 所有預設的 ♥ 總數 |
| 關注者 | 關注你的用户數 |
| 月度排名 | 你的發佈在當月的排名 |

## 認證管理

Microsoft 賬號的認證狀態 / 重新生成令牌 / 登出。賬號切換也在此進行。

## 版主功能（受限）

面向官方賬號成員的額外功能：
- 審核被舉報的預設
- 封禁 / 解封用户
- 發佈公告
