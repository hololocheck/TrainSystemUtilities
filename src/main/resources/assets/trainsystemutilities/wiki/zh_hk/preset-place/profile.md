# 個人資料

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__zh_hk.png)

查看用户公開作品和投稿情況的頁面。自己的個人資料從 PresetPlace 上方的名字・圖標打開，其他用户的從[作品詳情](detail.md)的投稿者名稱打開。

[[TOC]]

在自己的頁面中，可以查看公開作品數、累計下載數、點贊數和關注者數，並打開[創作者中心](creator-center.md)。在其他用户的頁面中，可以瀏覽公開作品並關注。

![](bws:trainsystemutilities:wiki/screens/profile-icon-editor__main__zh_hk.png)

支持的官方賬户會顯示個人資料圖標的編輯功能。可以讀取 SVG，並設置大小、位置、背景色和邊框顏色。普通賬户不顯示編輯按鈕。

登錄已過期時，打開界面時會自動重新登錄。
