# 上傳預設

![](bws:trainsystemutilities:wiki/screens/preset-place-upload__zh_hk.png)

將保存的自製編組提交到 Preset Place 申請公開。請將[瀏覽界面](../train-preset-tool/browse.md)切換為「我的預設」，並選擇目標的上傳圖標。添加圖片或發佈時會自動登錄。

[[TOC]]

添加 1〜5 張圖片，並輸入 1〜4,096 個字符的説明。圖片支持 PNG・JPG。説明中可以使用 Markdown 的標題、列表、鏈接、強調和引用。可以在預覽中確認顯示效果。

填寫完整後即可選擇「發佈」。請在確認界面中確認內容後提交。也可以用 Ctrl + Enter 進行發佈操作。申請內容經過審核後公開。

在可以使用 Preset Place 的環境中，自製的預設上會顯示上傳圖標。從 Preset Place 下載的作品上不會顯示。
