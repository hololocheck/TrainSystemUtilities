# 鐵路管理方塊的顯示器設置

![](bws:trainsystemutilities:wiki/screens/railway-management-settings__zh_hk.png)

從[鐵路管理方塊](../railway-management.md)的「設置」，更改站台號、文字大小和時鐘的顯示。

[[TOC]]

| 項目 | 設置方法 |
|---|---|
| 站台號 | 用滾輪選擇 0〜99。0 為不顯示 |
| 站台號的文字大小 | 用滾輪調整。0 為自動 |
| 站台號的位置 | 點擊切換左・右 |
| 時鐘 | 點擊切換顯示・不顯示 |
| 時鐘的文字大小 | 用滾輪調整。0 為自動 |

雙面顯示時，用「切換正/背面」選擇要編輯的面。每個面可以使用不同的設置。

## 批量應用 {#batch-apply}

啓用「批量應用」期間，對站台號・文字大小・站台號的位置・時鐘設置的更改會反映到登記在本方塊[顯示器連接卡](../tools/monitor-link-card.md)上的所有顯示器組。正面的設置反映到各組的正面，背面的設置反映到各組的背面。不會反映到其他鐵路管理方塊。初始狀態為啓用。要單獨更改時，請將其禁用。
