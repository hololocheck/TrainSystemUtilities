# 綠幕

```embed:item id=trainsystemutilities:green_back size=48 label=true
```

用作視頻或截圖背景的綠色（#00FF00）方塊。以亮度 15 發光。拍攝後，可以在視頻編輯軟件等中用於摳除綠色的色鍵合成。

與普通方塊一樣放置和拆除（回收需要使用鎬）。沒有專用界面。請鋪在車輛或建築的背面，覆蓋要拍攝的範圍。也可以用於製作 [Preset Place](../preset-place/upload.md) 的介紹圖片。

也鋪在拍攝對象下方會更容易摳圖，但可能會映入綠色。請根據拍攝方法和編輯方式調整擺放。
