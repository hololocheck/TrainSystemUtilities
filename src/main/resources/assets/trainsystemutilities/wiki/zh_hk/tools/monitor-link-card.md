# 顯示器連接卡

```embed:item id=trainsystemutilities:monitor_link_card size=48 label=true
```

專門用於登記顯示器顯示目標的卡片。手持卡片右鍵顯示器，會將相連的顯示器登記為一個組。再次點擊同一組會取消登記。

[[TOC]]

可以登記多個組，工具提示中會顯示已登記的顯示器方塊數。Shift + 右鍵會清除卡片上登記的全部內容。

要顯示時，請將登記好的卡片放入[鐵路管理方塊](../railway-management.md)、[海報管理方塊](../poster-management.md)或[管理用計算機](../management-computer/monitor.md)的顯示器槽位。不需要用卡片右鍵顯示源方塊。管理用計算機會使用卡片上最先登記的組作為顯示目標。如果顯示源的顯示器顯示已關閉，請將其打開（初始為打開）。

不僅支持單台顯示器，也支持縱橫拼接的顯示面。可以在整個顯示面上顯示列車信息、圖片和自定義佈局。
