# 逆變器佔位方塊

```embed:item id=trainsystemutilities:fe_inverter_dummy size=48 label=true
```

外觀和 3 方塊結構都與 [FE 逆變器](fe-inverter.md)相同的裝飾用設備。不集電、不蓄電，也不消耗 FE。

[[TOC]]

可以演出受電弓的升起、降下，以及接觸接觸網的樣子。在管理用計算機的電氣化詳情中會顯示「（裝飾模式）」。空手右鍵也不會顯示專用介面或電力資訊。

也可以和真正的 FE 逆變器一起搭載在列車上，此時由真正的逆變器管理電力。只有逆變器佔位方塊時無法儲存 FE。

也可以用作軌道旁設備箱等裝飾。合成 1 個 FE 逆變器會得到逆變器佔位方塊，合成 1 個逆變器佔位方塊會變回 FE 逆變器。取得用 ID 為 `trainsystemutilities:fe_inverter_dummy`。
