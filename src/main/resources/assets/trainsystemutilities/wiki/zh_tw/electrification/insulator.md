# 接觸網絕緣子

```embed:item id=trainsystemutilities:insulator size=48 label=true
```

用於安裝接觸網、並承接變電所供電的支撐點。右鍵想要放置的面：在地面上朝上、在天花板上朝下、在牆上朝側面放置。接觸網連接在絕緣子的頂端。

[[TOC]]

將[接觸網連線工具](wire-connector.md)切換到鋪設模式，依次右鍵起點和終點的絕緣子即可連線。一個絕緣子可以連接多條接觸網。

供電時，請從與[變電所](substation.md)相鄰的絕緣子連起接觸網網路。變電所的電力耗盡後，連接的接觸網也會斷電。破壞絕緣子時，連接到該絕緣子的接觸網會被拆除。

用[電力檢查器](power-checker.md)右鍵，可以查看連線數和通電狀態。
