# 受電弓

```embed:item id=trainsystemutilities:pantograph size=48 label=true
```

安裝在列車車頂的集電裝置。請在組裝列車之前，把它放在車頂的上表面。它會把從已通電接觸網接收的電力，送到同一列車的 [FE 逆變器](fe-inverter.md)。

[[TOC]]

作為方塊放置時，空手右鍵可在升起和降下之間切換。組裝後的列車，可以在管理用計算機的[列車詳情](../management-computer/trains.md)中操作。除了逐個切換，也可以一次升起或降下全部受電弓。管理用計算機只能切換同一節車廂上搭載了逆變器（包括逆變器佔位方塊）的受電弓，並且你需要位於列車 64 方塊以內。

升起和降下需要手動切換，受電弓不會配合接觸網自動動作。無論用哪種方式切換，都以最後一次操作為準。只有在升起狀態並接觸已通電的接觸網時才會集電。

## 多節編組時的行為 {#複數連結時の挙動}

受電弓和逆變器不必放在同一節車廂上，同一列車內可以共享電力。在離開接觸網的區間，列車使用儲存的電力。整列車的 FE 降到 0 時，列車會停下。位於未載入區塊中的列車既不集電，也不消耗 FE。
