# 佈局編輯器

![](bws:trainsystemutilities:wiki/screens/management-computer__layout-edit__zh_tw.png)

編輯顯示器上所顯示資訊的位置和大小。從管理用計算機的「佈局」開啟。

[[TOC]]

從面板欄中選擇線路圖、列車列表、時刻表、車站數、列車數、訊號機數、時鐘，並拖到預覽框中。

| 操作 | 效果 |
|---|---|
| 左鍵拖動面板 | 更改位置 |
| 在面板上滾動滾輪 | 更改大小 |
| 選中面板後按 Delete | 刪除面板 |
| 中鍵點選面板 | 設定文字大小（線路圖還可設定圖示大小） |
| 「全部清除」 | 刪除所有面板 |
| 「推薦」 | 放置推薦佈局 |
| 「儲存」 | 儲存設定並關閉 |

詳細設定的數值用滾輪調整。將值設為 0 時，會根據顯示器和面板的大小自動設定。按「推薦（自動）」可以一併恢復。

儲存的佈局會反映到連結到同一台管理用計算機的顯示器上。
