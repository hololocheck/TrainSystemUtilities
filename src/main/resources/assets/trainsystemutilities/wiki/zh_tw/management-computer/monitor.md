# 顯示器顯示

![](bws:trainsystemutilities:wiki/monitor/monitor-display__zh_tw.png)

*鐵路管理方塊的車站顯示器顯示示例（停靠中的列車・下一班停靠的列車・線路編號・站臺號・時刻）*

可以將管理用計算機的資訊顯示在已連結的顯示器上。線路圖、列車列表、時鐘等可以用佈局編輯器自由排列。

[[TOC]]

## 顯示步驟

1. 放置管理用計算機和顯示器。
2. 用[顯示器連線卡](../tools/monitor-link-card.md)登錄要顯示的顯示器。
3. 將登錄好的卡片放入管理用計算機的顯示器槽位。
4. 「顯示器」開關在初始狀態下為啟用。如果已禁用，請點選將其啟用。
5. 在「[佈局](layout-editor.md)」中放置面板並儲存。初始佈局為空，沒有面板時不會顯示任何內容。

用「[佈局](layout-editor.md)」設定面板的位置和大小，用「[顏色](color-settings.md)」設定各元素的配色。卡片上登錄了多台顯示器時，管理用計算機會顯示在最先登錄的顯示器上。
