# 線路圖

![](bws:trainsystemutilities:wiki/screens/management-computer__route-map__zh_tw.png)

可以在 2D 地圖上檢視已登錄的線路網。顯示站名、軌道的連線、列車的位置和訊號的狀態。

[[TOC]]

開啟管理用計算機，從左上角的列表中選擇「我的線路圖」。如果地圖沒有顯示，請用[儲存卡](../tools/memory-card.md)連結線路網。

| 操作 | 效果 |
|---|---|
| 左鍵拖動 | 移動顯示範圍 |
| 滾輪 | 放大・縮小 |
| 點選列車圖示 | 顯示列車詳情 |
| 點選車站圖示 | 在車站標籤頁中顯示車站詳情 |

點選時大幅移動滑鼠，會被視為移動地圖。
