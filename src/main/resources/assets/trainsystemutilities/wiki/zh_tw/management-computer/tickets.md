# 售票機標籤頁

![](bws:trainsystemutilities:wiki/screens/management-computer__tickets__zh_tw.png)

設定[自動售票機](../structure/ticket-vending-machine.md)上可選擇的目的地的介面。請在管理用計算機中選擇「售票機」。

[[TOC]]

此計算機線路網中的車站組會顯示在列表中。用各車站的開關切換是否作為目的地顯示。該設定在整個世界中共享，會反映到所有自動售票機。

如果車站沒有顯示，請先用[車站範圍指定工具](../tools/station-range-tool.md)登錄車站組。在尚未選擇任何目的地的初始狀態下，會顯示同一線路網中本站以外的所有車站。進行選擇後，只顯示選中的車站。
