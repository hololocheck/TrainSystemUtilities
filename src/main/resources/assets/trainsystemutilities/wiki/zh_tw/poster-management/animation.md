# 海報動畫設定

![](bws:trainsystemutilities:wiki/screens/poster-management-anim__zh_tw.png)

設定海報的切換方式。從[海報管理方塊](../poster-management.md)的「動畫」開啟。再次按同一按鈕或按 Esc 即可關閉。

[[TOC]]

從列表中選擇效果，用滾輪更改「間隔」和「速度」的值。間隔是每張圖片的顯示時間，速度是切換動作所需的時間。

| 效果 | 動作 |
|---|---|
| 無 | 不加效果直接切換 |
| 向左滑動／向右滑動 | 從左右滑入 |
| 向上滑動／向下滑動 | 從上下滑入 |
| 淡入淡出 | 逐漸切換 |
| 橫向翻轉 | 橫向收縮，像翻面一樣切換 |
| 放大 | 邊放大邊出現 |
| 縮放 + 淡出 | 邊縮小邊出現 |
| 左滑 + 淡出／上滑 + 淡出 | 以短距離滑動和淡化切換 |

可以在介面內的預覽中確認動作。預覽使用雙色樣本，而不是登錄的圖片。
