# 預設詳情

![](bws:trainsystemutilities:wiki/screens/preset-place-detail__zh_tw.png)

檢視公開作品的 3D 模型、圖片、說明和投稿者的介面。在 PresetPlace 的列表中點選作品即可開啟。

[[TOC]]

用「3D」開啟放大顯示，左鍵拖動旋轉，Shift + 左鍵拖動移動，滾輪縮放。縮放倍率為 0.2〜8 倍。按 Esc 或點選背景關閉。

用「下載」儲存到本地。儲存後可以從「我的預設」放置。再次點選可以取消點贊。選擇投稿者名稱會開啟[個人資料](profile.md)，也可以切換關注。

![](bws:trainsystemutilities:wiki/screens/preset-place-detail-report__zh_tw.png)

發現不當內容時，請開啟「舉報」，輸入 500 字以內的理由後提交。管理員會確認內容。
