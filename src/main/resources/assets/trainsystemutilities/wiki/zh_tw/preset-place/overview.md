# Preset Place 概述

```embed:item id=trainsystemutilities:train_preset_tool size=48 label=true
```

公開自製的列車預設，並查找和下載其他玩家作品的共享功能。登入時會自動使用當前登入遊戲的 Minecraft 賬戶。

[[TOC]]

將列車預設工具切換到 GUI 模式後右鍵，並將左上角的下拉選單切換為「PresetPlace」。選擇作品後，可以檢視 3D 預覽、圖片和說明（[預設詳情](detail.md)）。

可以為喜歡的作品點贊，或關注投稿者。下載的編組可以從「我的預設」放置。不當的投稿可以在詳情頁面附上理由進行舉報。

公開自己的作品時，在「我的預設」中選擇自製預設的上傳圖示（[上傳預設](upload.md)）。從自己的名字或圖示開啟[個人資料](profile.md)，可以在[創作者中心](creator-center.md)檢視投稿的反響。
