# 個人資料

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__zh_tw.png)

檢視使用者公開作品和投稿情況的頁面。自己的個人資料從 PresetPlace 上方的名字・圖示開啟，其他使用者的從[作品詳情](detail.md)的投稿者名稱開啟。

[[TOC]]

在自己的頁面中，可以檢視公開作品數、累計下載數、點贊數和關注者數，並開啟[創作者中心](creator-center.md)。在其他使用者的頁面中，可以瀏覽公開作品並關注。

![](bws:trainsystemutilities:wiki/screens/profile-icon-editor__main__zh_tw.png)

支援的官方賬戶會顯示個人資料圖示的編輯功能。可以讀取 SVG，並設定大小、位置、背景色和邊框顏色。普通賬戶不顯示編輯按鈕。

登入已過期時，開啟介面時會自動重新登入。
