# 上傳預設

![](bws:trainsystemutilities:wiki/screens/preset-place-upload__zh_tw.png)

將儲存的自製編組提交到 Preset Place 申請公開。請將[瀏覽介面](../train-preset-tool/browse.md)切換為「我的預設」，並選擇目標的上傳圖示。新增圖片或釋出時會自動登入。

[[TOC]]

新增 1〜5 張圖片，並輸入 1〜4,096 個字元的說明。圖片支援 PNG・JPG。說明中可以使用 Markdown 的標題、列表、連結、強調和引用。可以在預覽中確認顯示效果。

填寫完整後即可選擇「釋出」。請在確認介面中確認內容後提交。也可以用 Ctrl + Enter 進行釋出操作。申請內容經過稽核後公開。

在可以使用 Preset Place 的環境中，自製的預設上會顯示上傳圖示。從 Preset Place 下載的作品上不會顯示。
