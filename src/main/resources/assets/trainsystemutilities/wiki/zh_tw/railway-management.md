# 鐵路管理方塊

![](bws:trainsystemutilities:wiki/screens/railway-management__zh_tw.png)

顯示車站的列車資訊，並與顯示器、站臺遮蔽門和語音廣播聯動的設備。先手持物品右鍵 Create 的車站方塊，登錄車站。之後像普通方塊一樣放置，即可連結到該車站。

[[TOC]]

放置後右鍵會開啟介面。用[儲存卡](tools/memory-card.md)連結到[管理用計算機](management-computer/overview.md)後，車站的資訊可以用於運行管理。

![](bws:trainsystemutilities:wiki/screens/railway-management__zh_tw.png)

介面上顯示停靠中的列車和下一班到站的列車。可以檢視列車名、車廂數、到達・發車時刻、分配的線路編號等。下一班列車的列表會自動翻頁。

在顯示器行中，可以切換顯示的啟用・禁用，並操作「[設定](railway-management/settings.md)」「[顏色](railway-management/color.md)」。「功能」中會顯示站臺遮蔽門設定，安裝 SAS 時還會顯示廣播設定。數值在數值上滾動滾輪更改。

要將相同的設定反映到登錄在本方塊[顯示器連線卡](tools/monitor-link-card.md)上的多台顯示器時，請使用[批次應用](railway-management/settings.md#batch-apply)。請根據是否多人共同編輯，從頭像圖示選擇[公開・非公開](getting-started.md#access-mode)。
