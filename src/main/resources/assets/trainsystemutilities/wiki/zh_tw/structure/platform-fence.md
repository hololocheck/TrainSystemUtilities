# 站臺護欄

```embed:items size=32 cols=3 label=true ids=trainsystemutilities:platform_fence_1m,trainsystemutilities:platform_fence_3m,trainsystemutilities:platform_fence_5m
```

安裝在站臺邊緣的護欄。有 1m・3m・5m 三種可以區分使用，色帶的顏色可以根據線路更改。

[[TOC]]

面向要放置的方向並右鍵。護欄會向自己的左右兩側延伸。3m・5m 如果沒有所需的空餘寬度則無法放置。

要一併更改色帶顏色時，請用[儲存卡](../tools/memory-card.md)將相鄰的護欄和站臺遮蔽門登錄為一組。手持卡片時，可以用邊框確認登錄範圍。不需要的部分可以用 Shift + 右鍵移除（相連的部分會一起移除）。

將登錄好的卡片放入[鐵路管理方塊](../railway-management.md)的站臺遮蔽門設定中，並設定動作為「帶色」的條件。顏色從設定介面的色樣中選擇，會在停車・發車事件時改變。單獨右鍵護欄不會改變顏色。詳細的聯動步驟請參閱「[站臺遮蔽門](platform-screen-door.md#link)」。
