# 顯示器連線卡

```embed:item id=trainsystemutilities:monitor_link_card size=48 label=true
```

專門用於登錄顯示器顯示目標的卡片。手持卡片右鍵顯示器，會將相連的顯示器登錄為一個組。再次點選同一組會取消登錄。

[[TOC]]

可以登錄多個組，工具提示中會顯示已登錄的顯示器方塊數。Shift + 右鍵會清除卡片上登錄的全部內容。

要顯示時，請將登錄好的卡片放入[鐵路管理方塊](../railway-management.md)、[海報管理方塊](../poster-management.md)或[管理用計算機](../management-computer/monitor.md)的顯示器槽位。不需要用卡片右鍵顯示源方塊。管理用計算機會使用卡片上最先登錄的組作為顯示目標。如果顯示源的顯示器顯示已關閉，請將其開啟（初始為開啟）。

不僅支援單台顯示器，也支援縱橫拼接的顯示面。可以在整個顯示面上顯示列車資訊、圖片和自定義佈局。
