# 接觸網支柱自動放置工具

```embed:item id=trainsystemutilities:overhead_pole_auto_tool size=48 label=true
```

一種**手持工具**，可在你右鍵的鐵軌上的某一點放置一根[接觸網支柱](../electrification/overhead-pole.md)。先在設定介面中確定支柱高度、限界、並行鐵軌數量等引數，再切換到放置模式並右鍵鐵軌，即可在該處升起一根支柱。

## 開啟 / 持有

此工具有**兩種模式**。剛切換到該工具時，處於"GUI 模式"（設定介面）。

- **GUI 模式**（初始狀態）：右鍵開啟**設定介面**。在此調整支柱高度、與鐵軌的限界、並行鐵軌數量、桁架 / 絕緣子使用等。
- **選擇模式**：右鍵鐵軌**實際放置支柱**的模式。

用 **Alt + 滑鼠滾輪**切換模式（見下文"操作"）。手持時，當前模式會顯示在快捷欄上方。

## 用法

1. 手持工具並直接**右鍵**（預設為**滑鼠右鍵**）即可開啟**設定介面**。
2. 在設定介面中確定支柱高度、限界、並行鐵軌數量、桁架 / 絕緣子等（設定介面的操作請參見下方的[設定介面](#settings)）。
3. 用 **Alt + 滾輪**切換到**選擇模式**，再用 **Ctrl + 滾輪**切換到**"放置"**子模式。
4. 在需要支柱的位置**右鍵鐵軌**，即可在該處放置一根支柱（瞄準鐵軌時會出現半透明的預覽）。
5. 材料不足時，會以紅色顯示"材料不足"，且不會放置任何東西。

> [!NOTE]
> 在"放置"子模式下，若右鍵的不是鐵軌，會顯示"請右鍵鐵軌"，且不會放置任何東西。請務必瞄準 Create 的鐵軌。

## 設定介面 {#settings}

![](bws:trainsystemutilities:wiki/screens/overhead-pole-auto-settings__main__zh_tw.png)

- **高度 / 淨空 / 複線（數量）**：將游標移到數值上，用**滾輪**增減。
- **懸臂式 / 放置桁架 / 將絕緣子放置在線路正上方**：**點選**開關切換。
- **已連線倉庫**：提取材料的箱子 / ME 的狀態（手持工具時用 **Shift + 中鍵**連線箱子）。
- 右側預覽：**拖曳**旋轉，**Shift + 拖曳**平移，**滾輪**縮放。
- 點選 **"應用此設定 → 進入鋪設模式"** 會彈出確認；點選 **"進入鋪設模式"** 後切換到選擇模式的"放置"子模式並關閉介面。

## 操作（滾輪 / 點選）

| 輸入 | 動作 |
|---|---|
| **右鍵**（GUI 模式） | 開啟設定介面 |
| **右鍵**（選擇模式 / 放置） | 在瞄準的鐵軌點放置一根支柱 |
| **Alt + 滾輪** | 切換工具模式（GUI ⇔ 選擇）。但在"放置"子模式下，用於以 45° 為步長在 8 個方向旋轉支柱朝向 |
| **Ctrl + 滾輪** | 在選擇模式內切換子模式（回到 GUI / 放置） |
| **Shift + 滾輪** | 增大 / 減小支柱高度（與設定介面的"高度"為同一個值） |
| **Shift + 中鍵** | **將瞄準的箱子連結為材料庫**（支柱材料會自動從中抽取） |

> [!TIP]
> 高度和限界可在**設定介面**中調整。高度也可在手持時用 **Shift + 滾輪**調整。  
> 對於傾斜（超高）曲線和多線區段，可透過設定介面上的桁架選項切換為使用[接觸網架](../electrification/overhead-truss.md)的配置。
