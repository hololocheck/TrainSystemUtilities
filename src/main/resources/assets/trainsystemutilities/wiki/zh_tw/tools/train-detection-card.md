# 列車檢測卡

```embed:item id=trainsystemutilities:train_detection_card size=48 label=true
```

記錄軌道上一個檢測列車地點的卡片。與 SAS 聯動，用於配合列車通過播放廣播。

[[TOC]]

手持卡片，右鍵 Create 的軌道。記錄的座標可以在工具提示中檢視。Shift + 右鍵清除。只能登錄軌道。

登錄後，開啟[鐵路管理方塊](../railway-management.md)的廣播設定，將卡片放入檢測卡槽位。要播放的音源和條件在鐵路管理方塊一側設定。卡片本身沒有設定聲音或播放條件的介面。

{{/if}}
