# 瀏覽・放置預設

![](bws:trainsystemutilities:wiki/screens/train-preset-browse-mine__zh_tw.png)

選擇已儲存的編組、確認所需材料並進行放置的介面。將列車預設工具切換到 GUI 模式後右鍵。

[[TOC]]

## 選擇編組

用左上角的下拉選單在「我的預設」和「PresetPlace」之間切換。「我的預設」是本地儲存的編組，「PresetPlace」是 [Preset Place](../preset-place/overview.md) 上的公開作品。

選擇自己預設的圖塊會顯示 3D 預覽。左鍵拖動旋轉，右鍵拖動移動，滾輪縮放。選擇 PresetPlace 的圖塊會開啟詳情介面。右鍵自己預設的圖塊會開啟刪除確認。從自製預設的上傳圖示可以[申請公開](../preset-place/upload.md)。

公開作品可以按名稱搜尋，並按「最新」「熱門」「下載」「瀏覽」排序。下載後從「我的預設」中使用。

## 準備材料

將圖塊拖到右側面板，可以檢視所需材料。在補充來源按鈕上滾動滾輪，選擇 Chest 或 ME。手持工具 Shift + 中鍵點選箱子即可連結。

請從膠水儲罐的「補充」補給黏合劑（[材料補充](refill.md)）。「傾倒」會丟棄儲罐中的全部內容。

## 放置到世界中

按「使用此設定繼續」並在確認介面中確定後，會關閉介面並進入放置模式。在放置模式下，用 Alt + 滾輪在「起點」「旋轉」「放置」之間切換。在「起點」下右鍵軌道確定起點。方向會自動決定，需要時可以在「旋轉」下滾動 Ctrl + 滾輪，每次修正 90 度。在「放置」下右鍵即可放置，並消耗材料和黏合劑（創造模式下只消耗黏合劑）。

可以重試時用中鍵點選重試。用 Shift + 中鍵點選中止，並返回 GUI 模式。
